# 技術動向の調査チャネル

技術・開発トピック（プログラミング言語、フレームワーク、ライブラリ、ツール、
インフラ等）の動向調査では、性質の異なる複数チャネルを使い分ける。

| チャネル | 手段 | 向いている調査 |
|---|---|---|
| X（トレンド・ニュース要約） | `xapi` MCP（`search_posts_all`は現状403で使用不可。`get_trends_by_woeid`/`search_news`は利用可） | 「今何が話題か」という温度感、当事者の反応 |
| X（投稿検索・記事本文） | `socialdata-mcp`（自作、読み取り専用・従量課金） | キーワード/演算子での投稿検索、ツイート詳細、X Article本文取得。`url:x.com/i/article min_faves:N -filter:replies`でバズ記事だけを絞り込める |
| Hacker News | `hn-mcp`(自作、読み取り専用・無料） | 地味だが技術的に重要な話題。バズに依存しない評価軸 |
| Qiita | `qiita-mcp`（自作、読み取り専用・無料） | 日本語の実務Tips・ハウツー・実装例 |
| Zenn | `zenn-mcp`（自作、読み取り専用・無料） | Qiitaよりやや技術深度の高い記事・書籍 |
| はてなブックマーク | WebFetch（`https://b.hatena.ne.jp/hotentry/it.rss`等） | 日本のエンジニアの選別フィルターを通った質の高いシグナル |
| GitHub Trending | `gh`コマンドまたはWebFetch | 実際に採用され始めているOSSの実測 |
| 公式ブログ・リリースノート | WebFetch（RSS/Atom） | 話題化を待たない一次ソース。変更点の確定情報 |

`hn-mcp`/`qiita-mcp`/`zenn-mcp`/`socialdata-mcp`は読み取り専用ツールのみを提供する
自作MCPであり、`claude mcp list`で接続状態を確認できる。実行時にこれらのMCPが
利用可能でない場合は、存在を前提にせず、Web検索や各サービスの公開ページで代替する。

`socialdata-mcp`は他3つと異なりSocialData API（従量課金、目安1件あたり約0.03円）
をラップしているため、呼び出しごとにコストが発生する。大量件数を取得する調査では、
必要な範囲に絞り、目安のコスト感（件数×約0.03円）を意識する。数百件規模の取得など
コストが無視できない量になる場合は、実行前にボスへ一声かける。
